# ТРЕКЕР — Telegram Bot

Личный трекер: Дневник, Привычки, Задачи, Финансы.

## Разделы

- 📖 **Дневник** — записи с настроением (5 уровней)
- ⚡ **Привычки** — ежедневный трекинг, серия дней, прогресс за неделю
- ✅ **Задачи** — сегодня / краткосрочные / долгосрочные
- 💰 **Финансы** — доходы и расходы, баланс месяца

## Деплой на Railway

1. Зайди на [railway.app](https://railway.app) → Login with GitHub
2. New Project → Deploy from GitHub repo → выбери этот репозиторий
3. В настройках сервиса → Variables → добавь:
   ```
   BOT_TOKEN = <твой токен от @BotFather>
   ```
4. Railway запустит бота автоматически

> ⚠️ Никогда не добавляй токен в код или README — только через переменные окружения!

## Локальный запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=xxx python bot.py
```

## Стек

- Python 3.11+
- aiogram 3.x
- Хранение: JSON-файлы (легко заменить на SQLite/PostgreSQL)
